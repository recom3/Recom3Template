# Recon UI font support

This module comes from Recom3Ghost. It contains the original Recon Instruments `FontUtils.java` distributed with Snow2Liftie, plus Open Sans Regular and Bold. The loader reads the bundled fonts and caches them for use on API 16. For the original lists, dialogs and carousels, see the [full Recon UI source](https://github.com/gstarnet/sdk/tree/master/libraries/reconUI).
